# Открытие и прокрутка выдачи

- Назначение: открыть главную выдачу и просмотреть видимые результаты.
- Исходная страница: `https://hh.ru/search/vacancy` без приватных query-параметров.
- Предусловия: загруженная страница HH; авторизация желательна для персонализированной выдачи.
- До действия: публично подтверждены поиск, выбор региона, кнопка «Найти» и фильтры. В авторизованном Chrome присутствует страница выдачи.
- Локаторы: роль `button` с именем «Найти»; карточки `[data-qa="vacancy-serp__vacancy"]`; заголовки `[data-qa="serp-item__title"]`.
- Сеть: наблюдались служебные feature/telemetry запросы на публичной странице; в авторизованной DOM-пробе XHR/fetch отсутствовали. Тела не читались, URL очищались.
- Успех: есть хотя бы одна видимая карточка и одна допустимая ссылка `/vacancy/<number>`; прокрутка меняет `scrollY` или открывает дополнительные карточки.
- Ошибки: форма входа, challenge, пустая выдача, смена DOM, ошибка загрузки.
- Unknown outcome: страница открыта, но ни карточки, ни явное состояние пустой выдачи не распознаны.
- Повторная проверка: одна перезагрузка после watchdog; затем завершить без циклического скролла.
- Вмешательство владельца: CAPTCHA или уточнение поискового запроса. Автоматическое изменение поисковых предпочтений не выполняется.

после одного `PageDown` — 50. Предок заголовка содержит
`data-qa="vacancy-serp__vacancy"`; старый `data-qa="serp-item"` отсутствует.
